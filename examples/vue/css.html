What these results mean
  • Value preserved: a non-default declaration was captured and rasterized; its computed value matched after serialization in visible and hidden-page fixtures. This does not compare all rendered pixels.
  • Value mismatch: the recorded fixture changed its computed value after capture; inspect the before/after values in that row.
  • Browser unsupported: this browser rejects the property. This is not a PaperCurl rendering failure.
  • Native / frozen: interaction and timeline properties work on native pages; the turning texture is a still image.
  • Needs fixture: no usable non-default value was found automatically. This is unverified, not a pass.
  • The separate visual regression suite tests selected pixel regions, fonts, borders, masks, modern syntax, navigation, and worker behavior. Its recorded result is reported separately.
